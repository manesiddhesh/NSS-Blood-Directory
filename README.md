NSS Blood Directory
Project Description
The NSS Blood Directory is a web application developed to manage blood donation camps and track blood donors. The platform features two main modules: Blood Camp Management and Blood Donor Management. It allows volunteers to register, tracks their attendance, and generates automated activity reports. The blood camp module displays details of upcoming camps, including the time, venue, volunteer needs, and the organizing NGOs or hospitals.

Features
Blood Camp Management: Displays upcoming blood donation camps with details such as time, venue, volunteer requirements, and associated NGOs/hospitals.
Volunteer Registration: Allows volunteers to register and participate in blood donation camps.
Attendance Tracking: Tracks volunteer attendance at camps and generates reports.
Automated Activity Reports: Generates automated reports detailing volunteer activity and camp participation.
Blood Donor Management: Stores and manages donor information for future reference.
Contributions
Improved Event Management: Developed the blood camp management system, enabling efficient tracking of volunteer and donor details.
Volunteer Engagement: Implemented features for volunteer registration and attendance tracking, enhancing the management of volunteer resources.
Report Automation: Created automated activity reports, reducing administrative work and improving efficiency.
